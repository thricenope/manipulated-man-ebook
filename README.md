# 两性差距——被操纵的男人 · 阅读版

一个单文件电子书静态页面，基于《两性差距——被操纵的男人》（韦娜 著）的 HTML 阅读版制作。

## 在线阅读

> 部署完成后访问：<https://thricenope.github.io/manipulated-man-ebook/>

## 功能

- 单文件 `index.html`，零依赖，无需构建
- 章节目录抽屉，支持章节跳转与上一篇/下一篇导航
- 字号调节（A− / A+）、浅色/深色主题切换（自动跟随系统 + 手动切换）
- 顶部阅读进度条、回到顶部按钮
- 移动端适配（安全区、抽屉式目录）、桌面端侧栏布局、支持打印

## 本地阅读

直接用浏览器打开 `index.html` 即可，无需任何服务器。

## 部署方式

通过 GitHub Pages 部署，来源为 `main` 分支根目录。更新内容只需提交并推送 `index.html`，页面会自动更新。
